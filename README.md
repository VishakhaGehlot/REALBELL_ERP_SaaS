# Enterprise ERP Management System

## About the Project

Enterprise ERP Management System is a web-based application developed collaboratively to support business operations, including employee, project, and attendance management.

The application is built using Node.js, Express.js, EJS, MongoDB, and Bootstrap. It follows a modular structure to organize backend logic, database operations, routes, middleware, and frontend views.

## Key Features

- **Employee Management:** Manage employee-related records.
- **Project Management:** Handle project-related information.
- **Attendance Management:** Support attendance-related operations.
- **Authentication & Sessions:** Handle login and session-based access.
- **CRUD Operations:** Create, read, update, and delete application records.
- **Role-Based Access:** Control access based on user roles.
- **SMS Functionality:** Includes SMS-related functionality.
- **Debugging & Testing:** Identify issues and test application functionality.
